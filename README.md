# Soficraft — Site vitrine pour créatrice de bijoux

> Projet portfolio développé pour **[JohanWebStudio](https://johanwebstudio.fr)**.  
> Site immersif et narratif mettant en valeur le travail artisanal d'une créatrice de bijoux  
> à travers une expérience web sensorielle pilotée par le scroll.

## 🚀 Stack

| Catégorie | Technologie |
|-----------|------------|
| Framework | Next.js 15 (App Router) |
| Langage | TypeScript |
| Styling | Sass (architecture 7-1, BEM) |
| Animations | GSAP (ScrollTrigger, timelines) |
| Déploiement | Vercel |

---

## 📁 Architecture

```
soficraft/
├── src/
│   └── app/          # Pages et layouts (App Router)
└── public/           # Assets statiques (images, fonts)
```

---

## ✨ Features

- **Scroll storytelling** — narration visuelle pilotée par le scroll via GSAP ScrollTrigger
- **Animations avancées** — parallax, révélations, timelines séquencées
- **Design premium artisanal** — typographie soignée, palette raffinée, espacements généreux
- **CSS/Sass custom** — zéro framework UI, design 100% sur mesure
- **Responsive mobile-first**
- **Performances optimisées** — Next.js SSR, images optimisées
